# Security policy

WebDAV-sync is an Android app that syncs folders you choose with WebDAV servers you configure. Credentials stay on the device. The project does not run a hosted sync service.

## Supported versions

Security fixes are published in the current release on [GitHub Releases](https://github.com/offsyanka99/WebDAV-sync/releases). Older releases are not maintained.

| Version | Supported |
| --- | --- |
| 1.2.x | Yes |
| Older | No |

## Reporting a vulnerability

Email [hummersoft@mailbox.org](mailto:hummersoft@mailbox.org). Please do not open a public GitHub issue for an undisclosed vulnerability.

Include:

- The app version (About screen or the release tag).
- What you observed and how to reproduce it.
- Whether the issue is in the app, in a configured WebDAV server, or in the push path (Google Play / FCM or UnifiedPush).

You should receive an acknowledgement within a few days. A fix, when one is needed, ships in a release on this repository. Please give the maintainer a reasonable time to investigate before any public write-up.
